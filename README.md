

\# NYC Taxi Exploratory Data Analysis



\## Overview

This project explores NYC Yellow Taxi trip data to understand trip patterns, fares, travel duration, payment methods, tips, and demand over time.



\## Tools Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## Project Workflow

1\. Load and inspect the data

2\. Clean missing values and duplicates

3\. Remove invalid or unrealistic records

4\. Create features such as trip duration, pickup hour, and tip percentage

5\. Analyze trip patterns, fares, and payment methods

6\. Visualize trends and summarize insights



\## How to Run

1\. Install the required Python libraries.

2\. Obtain the dataset and place it in the expected local path.

3\. Open `NYC\_Taxi\_EDA.ipynb` in Jupyter Notebook.

4\. Run the cells in order.



\## Note

The raw taxi dataset is not included in this repository.
